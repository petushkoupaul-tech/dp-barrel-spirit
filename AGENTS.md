# Правила для AI-агента

Этот репозиторий содержит рабочий лендинг DP Barrel & Spirit. При возвращении к проекту без контекста из чатов сначала изучить текущее состояние файлов и только потом вносить изменения.

## Основные правила

- Сначала анализ текущего состояния и diff, потом правки.
- Не менять `index.html`, `styles.css`, `script.js`, изображения и рабочую верстку без явного запроса.
- Не менять структуру Hero без отдельного разрешения.
- Не добавлять бургер-меню или мобильную навигацию без отдельного запроса.
- Не менять размеры контейнеров каруселей без отдельного запроса.
- Не обрезать важные объекты на фото.
- Сохранять текущую премиальную ремесленную эстетику.
- Проверять мобильные ширины 360 px, 390 px и 430 px.

## Изображения

- Не заменять изображения массово без явного запроса.
- При работе с фото следить, чтобы важные объекты не были обрезаны.
- Если нет нормального инструмента для WebP или сжатия изображений, остановиться и сообщить об этом.

## Перед завершением работы

- Показать итоговый diff.
- Перечислить измененные файлы.
- Сообщить, какие проверки выполнены.
- Не делать commit без подтверждения владельца проекта.
