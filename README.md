# DP Barrel & Spirit

DP Barrel & Spirit - лендинг ремесленных деревянных бочек.

Проект сделан как статический сайт без фреймворков:

- HTML
- CSS
- JavaScript

Основная ссылка: https://dp-barrel-spirit.vercel.app/

Деплой выполняется через Vercel.

## Локальный запуск

Открыть `index.html` через Live Server в VS Code.

## Базовый рабочий процесс

1. Внести правки.
2. Проверить сайт локально.
3. Проверить состояние репозитория:

```bash
git status
```

4. Добавить нужные файлы:

```bash
git add <files>
```

5. Создать commit:

```bash
git commit -m "Описание изменений"
```

6. Отправить изменения:

```bash
git push
```

После push Vercel автоматически запускает деплой.
