# Правила изображений

## Формат

- Для новых изображений использовать WebP.
- Для каруселей предпочтительный формат кадра - 4:5.
- Рекомендуемый размер для каруселей - 1200x1500 px.
- Рекомендуемое качество WebP - около 80-82.

## Имена файлов

- Не использовать случайные длинные имена.
- Для серийных изображений лучше использовать простые имена:
  - `01.webp`
  - `02.webp`
  - `03.webp`

## Оригиналы

Оригиналы PNG/JPG хранить отдельно вне деплоя, чтобы не утяжелять публичную версию сайта.

## Обновление каруселей

При обновлении карусели менять только нужный блок HTML. Не переписывать соседние секции и не менять размеры контейнеров без отдельного запроса.

Перед заменой изображений проверить:

- важные объекты не обрезаны;
- пропорции подходят под текущий контейнер;
- файл оптимизирован;
- имя файла понятное и короткое.
