# Деплой

Проект деплоится на Vercel. Основная ссылка:

https://dp-barrel-spirit.vercel.app/

## Проверить статус Git

```bash
git status
```

Команда показывает измененные, новые и удаленные файлы.

## Сделать commit и push

1. Проверить изменения:

```bash
git diff
```

2. Добавить нужные файлы:

```bash
git add <files>
```

3. Создать commit:

```bash
git commit -m "Описание изменений"
```

4. Отправить изменения:

```bash
git push
```

## Как работает Vercel

Vercel подтягивает изменения из ветки `main`. После `git push` в `main` должен автоматически начаться новый деплой.

Deployments смотреть в панели проекта Vercel на вкладке Deployments.

После завершения деплоя обновить страницу через Ctrl+F5, чтобы браузер не показывал старую версию из кеша.

## Если деплой не стартовал

- Проверить, что изменения отправлены в ветку `main`.
- Проверить `git status`, чтобы убедиться, что нет незакоммиченных нужных файлов.
- Открыть панель Vercel и посмотреть вкладку Deployments.
- При необходимости запустить redeploy вручную в Vercel.
