# Контекст проекта

DP Barrel & Spirit - атмосферная презентация ремесленного бренда деревянных бочек. Это не интернет-магазин: задача лендинга - передать эстетику, качество материалов и ручную работу, а не вести пользователя через каталог с корзиной.

## Цель

Показать бренд как премиальный ремесленный проект, связанный с традицией, выдержкой и натуральными материалами.

## Ключевые ассоциации

- дерево
- металл
- выдержка
- ручная работа
- натуральные материалы
- мастерская
- ремесленная точность

## Основные секции

- Hero
- О проекте
- Коллекция изделий
- Детали
- Мастерская и ремесло
- Выдержка и использование
- Контакты
