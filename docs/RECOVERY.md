# Восстановление

Этот файл содержит базовые команды для проверки состояния проекта и отката ошибок.

## Проверить состояние

```bash
git status
```

Показывает, какие файлы изменены, добавлены или удалены.

## Посмотреть последние коммиты

```bash
git log --oneline -10
```

Показывает последние 10 коммитов в коротком виде.

## Посмотреть текущие изменения

```bash
git diff
```

Показывает изменения, которые еще не добавлены в commit.

## Откатить один файл

```bash
git restore <file>
```

Пример:

```bash
git restore index.html
```

Эта команда вернет файл к состоянию последнего commit.

## Вернуться к последнему commit

Для отдельных файлов использовать:

```bash
git restore <file>
```

Для всех незакоммиченных изменений можно использовать:

```bash
git restore .
```

Перед таким откатом обязательно проверить `git status` и `git diff`, чтобы не потерять нужную работу.

## Важное предупреждение

```bash
git reset --hard
```

Эта команда удаляет незакоммиченные изменения. Использовать ее только при полном понимании последствий и после отдельного подтверждения.
